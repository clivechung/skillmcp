# Test-Driven Development (TDD)

TDD ensures robust software through disciplined iteration.

## The Loop
1. **Red**: Write a failing test for a single public seam.
2. **Green**: Write the minimal code to pass the test.
3. **Refactor**: Clean up the architecture while maintaining 100% green tests.
